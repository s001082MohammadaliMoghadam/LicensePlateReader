# AI Usage Declaration

AI was used for brainstorming project scope, reviewing architecture alternatives, drafting explanations, suggesting tests, improving documentation, and troubleshooting openFrameworks/C++ workflow questions. I verified the computer-vision steps against OpenCV documentation and reviewed the generated code before integrating it.

Sample prompts:

- Suggest a small C++17/openFrameworks architecture for a license plate detector with a replaceable OCR component.
- Review this contour-filtering logic for edge cases and ownership issues.
- Explain how to demonstrate memory safety in a Windows Visual Studio C++ project.
- Suggest Yellowdig progress evidence for a failed image-processing experiment.

I did not submit AI output without review. I made the final decisions about scope, code integration, testing, screenshots, documentation, and presentation.
